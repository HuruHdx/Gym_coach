## 3. 计划模板模块（工单已展开）

完整表结构、接口、后台配置台、H5 页面与落地顺序见 [`计划模板模块-实现工单.md`](./计划模板模块-实现工单.md)；后台侧配置台说明在 `gym-admin/docs/07-计划模板后台配置台.md`。

要点：
- **两类模板**：框架型（三 / 四分化，槽位检索填充、可换动作）；成品型（动作组次锁定，仅伤病 / 缺器械降级替换）。
- **三层结构**：`PlanTemplate` → `PlanBlock` → `PlanExercise`（字段见主工单 §2 定稿）。
- **链路衔接**：按**板块**展开成今日草稿 → `/api/training/adopt`（写入 `plan_*` 溯源）→ 打卡 / 1RM 复用；热身组走 `warmup_sets` + `TrainingSetLog.is_warmup`。

## 修复：Tailwind 透明度工具类整条丢失（已改，未提交）

**症状**：`bg-ink/40`、`border-line/60`、`bg-accent/20` 等 27 处类不生成任何 CSS。
构建不报错，只是产物里没有这条规则。

**根因**：`tailwind.config.js` 的颜色写成 `var(--accent)`，Tailwind 3 无法给裸 CSS 变量加 alpha，
`<alpha-value>` 拿不到数值就整条跳过。

**修法（三处联动）**
1. `gym-ui/tokens.css`：三个主题各补 15 个 `--x-rgb: R G B` 三元组（用脚本从 hex 生成，避免手抄）。
2. `web/src/tailwind.config.js`：颜色统一改 `rgb(var(--x-rgb) / <alpha-value>)`。
3. `web/src/index.css`：保留 `.text-accent` / `.bg-ok\/15` 等**刻意的语义覆盖**并加注释——
   `text-accent` 必须走 `--accent-text`（填充色不能当文字），`bg-ok/15` 必须是 `--done-bg`（不透明浅色）。

**连带修复**：`bg-ink/40` 在深色主题下会变成 40% 白雾（`--text-1` 在深色是近白），
新增 `.bg-scrim { background-color: var(--mask) }`，替换 6 处遮罩
（SessionDetailSheet / cards.tsx Sheet / MePage WeightSheet / RepsStepper / SwapExerciseModal / WeightPickerModal）。

**验证**：无头 Chrome 读 `getComputedStyle`，三主题逐项确认
（lavender 遮罩 rgba(28,22,50,.42)、dark 遮罩 rgba(0,0,0,.62)）；
源码里 27 个 alpha 变体 27/27 生成；`tsc -b` + `vite build` 通过。
自检页留在 `web/style-check.html`（不参与构建，链接哈希 CSS，每次 build 后要改）。

**若回滚**：还原 tokens.css / tailwind.config.js / index.css 三处即可，其余是遮罩类替换。

## 已实现：长对话评测（未提交）

**为什么需要新接口**：`/api/eval/qa` 每次新建内存库、无状态，多轮只能靠 YAML 手工写 history。
但「上一版草稿里有几个动作、哪几个被伤痛 drop」只有模型自己知道，手抄必然与真实链路脱节。

**新增 `POST /api/eval/thread`**（`routers/brain.py`）
- 一次请求带完整 `turns`，**同一个内存库里顺序跑**
- 每轮把产出的 `card` 自动转成下一轮的 `draft_items`（只带 selected，meta 原样传递）
- 没出卡的轮（问答/闲聊）**沿用旧草稿**，不会被冲掉
- `adopt_after: N` 可选，最后把草稿真的落库（走 `session_service.adopt_draft`）
- 单轮异常写进 `error` 字段并标出第几轮，不整体 500

返回每轮：route / topic / draft_relation / session_target / card_title / 条目数 /
选中数 / **dropped**（validate 因伤痛剔除的）/ text_block。

**评测套件**（`eval/`）
- `cases-long.yaml` 18 条：L1 改稿 4 / L2 换部位 2 / L3 伤痛跨轮 3 / L4 夹问答 2 /

  draft_relation 的语义差别

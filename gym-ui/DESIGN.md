# Gym UI 规范

> 这份文件是**唯一事实来源**。`tokens.css` 是它落地的代码。
> 人和 AI 都读这一份；有冲突时以本文件为准。

## 0. 设计上下文（改之前先读这段）

| 项 | 内容 |
|---|---|
| 谁用 | 一个人自己用，不是给别人用的产品 |
| 在哪用 | 手机上，装在主屏幕；健身房现场 + 家里躺床上看 |
| 现场条件 | 组间休息十几秒、手上有汗、光线乱、单手操作 |
| 要解决 | 打开就知道今天练什么；勾完就算完成；下次计划能读到上次的记录 |
| 气质 | 干净、有分量、不讨好；不做"科技感"、不做霓虹 |

**这条最重要**：这是工具，不是社交媒体。留白和克制的优先级高于"炫"。

## 1. 颜色：五个角色，不许混用

| 角色 | 变量 | 怎么用 | 绝不能怎么用 |
|---|---|---|---|
| 页面底 | `--bg` | 整页背景 | 不要用纯白当页面底 |
| 卡片面 | `--surface` | 卡片、输入框、Tab 栏 | — |
| 强调填充 | `--accent` | 按钮底、进度条、勾选圆点、图表线 | **不能当文字色** |
| 强调文字 | `--accent-text` | 小字、图标、链接、选中态文字 | 不能当大面积填充 |
| 填充上的字 | `--accent-ink` | 压在 `--accent` 上的文字 | — |

### 为什么拆三个

亮色品牌色（青、绿黄、浅紫）直接当文字会失去可读性。实测：

| 组合 | 对比度 | 结论 |
|---|---|---|
| 亮青 `#06b6d4` 当白底文字 | 1.29–2.43 | ✗ 等于看不见 |
| 绿黄 `#c9f232` 当白底文字 | **1.29** | ✗ |
| 深青 `#0a6c7d` 当文字 | 5.79 | ✓ |
| 深墨字压在绿黄填充上 | 13.11 | ✓ |

**规则**：任何文字对背景的对比度 **≥ 4.5**。三级辅助文字（`--text-3`）最容易犯这个错——深色主题里我把它写成 `#74717f`，只有 3.94，小字全糊。现在的最小值是 `#94919f`（5.2–5.8）。

### 完成态用独立的绿

`--done` / `--done-text` / `--done-bg` 和强调色分开。这样换主题时勾选的绿不变，识别稳定。
（例外：森绿/薄荷主题里两者合并成一个色，那是刻意的。）

## 2. 字号：五级，不新增第六级

```
--fs-display 26px  页面大标题    一屏只用一次
--fs-title   17px  区块标题、动作名
--fs-body    15px  正文、数字主值
--fs-meta    13px  次要说明
--fs-label   12px  标签、按钮文字
--fs-micro   11px  辅助信息、单位
```

字重只有 **400 / 500 / 600** 三档，600 只给大数字和大标题。
**不要**用 700 硬撑层级——那是"看起来重要"，不是"真的是标题"。

数字一律加 `.num`（`tabular-nums`），否则列表右列对不齐。

---

## 3. 间距与圆角

间距只用 4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 32。
页面左右留白统一 `--page-x: 16px`，不要一页 12 一页 20。

圆角四档：`--r-sm 6` / `--r-md 9` / `--r-lg 14` / `--r-xl 18`。
**不要**所有元素同一个大圆角——那是"AI 感"最明显的来源之一。

---

## 4. 动效：只动两个属性

**硬规则**：只允许动画 `transform` 和 `opacity`。`width` / `height` / `top` / `left` 一律改为 `transform`。

```css
/* 进度条：用 scaleX，不用 width */
.bar > i { transform: scaleX(0); transform-origin: left; }

/* 抽屉：用 translateY */
.sheet { transform: translateY(101%); }
```

| 时长 | 用途 |
|---|---|
| 120ms | 按压反馈（`:active` → `scale(.98)`） |
| 180ms | 状态变化（勾选、选中） |
| 300ms | 位移、展开、抽屉 |

缓动只用 `--ease-out: cubic-bezier(.25,1,.5,1)`。**不要回弹/弹性**——那是玩具感，不是工具感。

其他：
- 按压反馈在**按下瞬间**给，不要等 `click`
- hover 一律收进 `@media (hover:hover) and (pointer:fine)`，否则触屏点完会粘住
- 必须有 `prefers-reduced-motion` 降级
- 动效不承载唯一信息（色弱/前庭敏感用户也要看得懂）

---

## 5. 移动端基线（这 6 条漏一条就会"像网页"）

1. `input { font-size: 16px }` —— 低于 16px，iOS 聚焦会强制缩放页面且不缩回
2. `<meta name="viewport" content="... viewport-fit=cover">` —— 否则 `env(safe-area-inset-*)` 全是 0
3. `-webkit-tap-highlight-color: transparent` —— 去掉点击灰块
4. `touch-action: manipulation` —— 去掉 300ms 延迟
5. `overscroll-behavior: none`（html）+ `contain`（滚动容器）—— 不劫持下拉刷新、不带着整页弹
6. 容器高度用 `100dvh`，不用 `100vh`

## 6. 组件清单（复用这些类，不要另起一套）

见 `components.css`：`.screen` `.appbar` `.card` `.statrow` `.listrow` `.checkdot`
`.btn` `.pill` `.chip` `.field` `.bar` `.ring` `.tabbar` `.mask` `.dialog` `.sheet` `.banner` `.empty`

### 三个必须记住的组件规则

**组勾选**：完成时**整行铺 `--done-bg`**，不是只点亮小圆点。这是扫一眼能看出练到第几组的关键。

**弹窗 vs 抽屉**：
- 弹窗 → "必须做决定、不能忽略"的一件事（如"结束今天的训练？"）
- 抽屉 → "要多看一眼再选"的列表（如替换动作，每项要带决策依据）

**空状态**：必须告诉人下一步做什么，不是画个插画。
> ✗ "暂无数据"
> ✓ "客户编号是 8 位数字，姓名输一个字就够" + 「清空搜索」按钮

## 7. 页面模板

### 标准页结构（顺序固定）

```
.appbar      标题 + 副标题（右上一个 pill 动作）
.statrow     3 个关键数字（可省）
.banner      状态提示（可省）
.scroll-y    主内容（卡片 / 数据行 / 分组）
[底部操作]   最多一个主按钮 + 一个次按钮
.tabbar      今日 / 训练 / 饮食 / 我的
```

### 各页职责

| 页面 | 一句话职责 | 主按钮 |
|---|---|---|
| 今日 | 今天做什么，勾完就算完成 | 采纳这份计划 |
| 训练 | 回看哪天练了什么、多少量 | 无（纯浏览） |
| 饮食 | 今天吃了多少，还差多少 | 拍照记一餐 |
| 我的 | 画像 + 周报 | 生成海报 |
| 教练 | 问一句，答案落成卡片 | 发送 |

### 教练页特别规则
**回复必须落成卡片**，不能是纯文字。卡片里要有可执行动作（采纳 / 记进今天 / 应用到计划）。
否则它就变成聊天工具，不再是计划工具。

## 8. 海报（分享用，规则和界面相反）

| | 界面 | 海报 |
|---|---|---|
| 标题 | 标签（"推日"） | **一句话**（"卧推破 28 公斤"） |
| 目的 | 快速分类 | 让人想转发 |
| 颜色 | 主色淡紫 | 深蓝青黄也可以（分享场合另算） |

海报必须有：一句人话总结 + 至少一个数字焦点 + 品牌标。
纯数据海报没人愿意转。

---

## 9. 硬规则速查（这些是踩过的坑）

| ❌ 不要 | ✅ 要 |
|---|---|
| 卡片套卡片 | 发丝线（`0.5px solid var(--line)`）分隔 |
| 每张卡都塞一个填充按钮 | 每屏**只有一个**主按钮 |
| emoji 当图标 | 同族线条 SVG，1.5–2 的 stroke |
| 所有元素同一个大圆角 | 按层级用 6/9/14/18 |
| 纯黑 `#000` 大面积 | `#17161c` 这类带倾向的近黑 |
| `color-mix()` | 预定义变量（微信 X5 旧内核不支持，会整条失效） |
| 填充式假文案（"快速查找您的信息"） | 真实数据密度（"共 1,284 位"） |
| 只在 click 上给反馈 | `:active` 或 `pointerdown` |

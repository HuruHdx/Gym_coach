# Gym Coach H5 · V2 视觉提案与 AI 实施手册

> 状态：提案，不自动覆盖 `DESIGN.md`。  
> 视觉预览：`ui-preview/h5-refresh.html`。  
> 目标：从“个人自用工具”升级为“可展示、可持续使用的训练产品”。

## 0. 与当前规范的关系

当前 `DESIGN.md` 强调健身房现场的克制和效率，这些原则继续保留：

- 单手可操作
- 打开就知道今天练什么
- 组间十几秒内完成记录
- 完成态一眼可见
- 不用装饰干扰训练

V2 增加三项：

- 品牌首屏更有辨识度，适合给新用户看。
- 动作图片、动图和短视频成为核心内容层。
- 今日、趋势、周报具备更强的成果展示感。

正式采用 V2 时，应把本文件确认后的内容合并进 `DESIGN.md`，不要长期维护两个互相冲突的事实来源。

## 1. 设计方向

一句话：

> 清爽训练工具 + 有分量的运动品牌感。

视觉关键词：

- 克制、清晰、有力量
- 浅灰紫页面、白色内容面、单一高饱和强调色
- 标题和关键数字有冲击力，正文保持耐读
- 动作内容使用大图面，业务列表保持紧凑
- 不做紫色渐变 AI 氛围，不做社交平台式信息流

## 2. 页面层级

### 品牌层

登录、首次引导、周报海报允许更强视觉：

- 超大标题
- 深色品牌底
- 配重片或训练轨迹抽象图形
- 单次入场动效

### 内容层

动作库、动作详情、训练趋势：

- 图片或动作示意优先
- 标签只展示决策所需信息
- 数据与内容并重

### 操作层

今日训练、组勾选、重量修改：

- 继续保持最克制
- 大点击区域
- 不使用大图抢占操作空间
- 一个屏幕只有一个主操作

## 3. Token

继续使用：

- `gym-ui/tokens.css`
- `gym-ui/base.css`
- `gym-ui/components.css`

不得在页面组件中新增裸色值。主题继续通过：

```js
document.documentElement.dataset.theme = "lavender";
```

切换。

推荐默认主题：

- 展示与大众用户：`lavender`
- 清爽运动感备选：`mint`
- 夜间训练：`dark`

主题切换只改变语义 Token，不在 React 组件中判断主题。

## 4. 页面结构

### 品牌引导

- 首屏只讲一句价值：“记录一次，下次更懂你。”
- 目标选择直接进入画像流程。
- 不放三列功能卡，不先解释 AI。
- 用户完成目标、经验、频率、伤痛后再生成第一份计划。

### 今日

首屏顺序固定：

1. 今日分化与预计时长
2. 当前训练状态 Hero
3. 三个关键数字
4. 今日动作列表
5. 唯一主按钮

Hero 只用于状态与一句训练目标，不放无关图片。

### AI 教练

- 初始页展示 3 个高价值快捷问题。
- AI 回复必须落成可执行卡片。
- 卡片必须有“应用到今日计划”“加入动作”“记录数据”之一。
- 长解释折叠，先展示结论和依据。

### 训练

- 顶部显示本周训练次数、完成组数和训练容量。
- 趋势图只显示一个主要指标，避免多轴复杂图。
- 最近训练列表支持进入单次详情。
- 动作趋势作为二级入口，不新增底部 Tab。

### 动作库

- 两列网格。
- 排序：练过优先 → 主力动作 → 有素材优先。
- 卡片展示动作名、关键靶区、练过状态和素材状态。
- 搜索支持中文名、英文名、别名和器械。

### 动作详情

- 素材按 `demo → start/end → 显式占位` 降级。
- 顺序：动态演示 → 名称与风险 → Cue → 4 步教案 → Mistakes。
- 底部固定唯一主按钮“加入今日训练”。
- 高光视频是内容入口，不自动播放。

### 我的

- 用户画像摘要优先。
- 周报使用更强的深色品牌卡。
- 设置项保持普通列表，不全部卡片化。
- “生成训练海报”是唯一主按钮。

## 6. 图片与视频

- 动作库统一使用 1:1 或 4:3 媒体比例。
- 同一列表不能混用不同裁切方式。
- 图片缺失时显示明确动作占位，不显示破图。
- GIF/视频进入视口后才加载。
- 高光视频默认静音封面，用户主动点击播放。
- 今日执行页不使用大图。

## 7. 动效

只动画 `transform` 和 `opacity`。

- 页面进入：8px 上移 + 淡入，300ms。
- 卡片按压：`scale(.98)`，120ms。
- 勾选：圆点缩放 + 整行完成底色立即切换。
- Hero 圆环装饰：只在页面进入时轻微缩放，不持续转动。
- 列表可错开 40ms 入场，但总数超过 8 条时不逐项动画。
- 视频播放、加载状态不能靠循环闪烁表达唯一信息。
- 必须提供 `prefers-reduced-motion`。

## 8. 响应与可访问性

- 页面容器使用 `100dvh`。
- 输入框、选择器、文本域字号固定为 16px。
- 主要点击区域不小于 44px。
- 文本对背景对比度不低于 4.5。
- 亮色强调色不能直接作为小字，文字使用 `--accent-text`。
- hover 只放在 `(hover: hover) and (pointer: fine)` 中。
- 数字容器必须添加 `.num`。
- 状态不能只用颜色，必须同时有文字或图标。
- 支持安全区、软键盘和 reduced-motion。

## 9. AI 分页实施方式

不要让 AI 根据截图自由发挥整站。采用以下顺序：

1. 给 AI 本文件、`DESIGN.md`、Token 和组件 CSS。
2. 一次只指定一个页面。
3. 同时提供页面职责、真实字段和验收状态。
4. 要求先复用组件，再增加业务组件。
5. 每页完成后运行构建、类型检查和移动端截图。
6. 所有页面完成后再统一调整视觉，不在开发中途反复改 Token。

推荐顺序：

1. 品牌引导
2. 今日与训练执行
3. 动作库与动作详情
4. AI 教练
5. 训练趋势
6. 我的与周报

## 11. 验收清单

- 新用户 5 秒内知道产品能解决什么。
- 今日页首屏能看到当前动作和下一步操作。
- 健身房单手操作不因视觉升级而变慢。
- 动作库有内容感，但不变成图片社交信息流。
- AI 回复可以直接转成计划或记录。
- 每屏主操作唯一。
- 深浅主题均无低对比文字。
- 无裸色、裸圆角和页面私有设计体系。
- 320px 宽度不横向溢出。
- 关闭动效后功能与信息完整。
